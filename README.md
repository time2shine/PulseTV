# PulseTV

> **High-Performance Android TV & Mobile Streaming Application**  
> Developed by **Muhammad Rokonujjaman**

PulseTV is a next-generation IPTV streaming platform engineered specifically for Android TV, Google TV, Fire TV, and Android mobile devices. Purpose-built around low-latency HLS/TS streaming, zero-touch Trakt synchronization, and automated library management.

---

## Key Features

- **Blazing Fast Playback**: Custom ExoPlayer/Media3 pipeline engine optimized for instant channel switching and stable long-session live streaming.
- **Dedicated IPTV Architecture**: Built exclusively to interface with high-performance Xtream Codes API backends.
- **Zero-Touch Trakt.tv Integration**:
  - Side-by-side QR code activation for effortless mobile phone login without clunky TV remote typing.
  - Automatic watch history synchronization across all devices.
  - Automatic Trakt favorites/watchlist import directly into your local library.
  - Automatic continuous playback scrobbling.
- **Smart Android TV Interface**:
  - D-pad optimized navigation designed for TV remotes.
  - Interactive Electronic Program Guide (EPG).
  - Pinned categories, customizable home shelves, and Continue Watching queues.
- **Automated In-App Updates**: Seamless update checks and 1-tap installation directly from this repository.
